# Contributing to DevOrchestrator

DevOrchestrator, or Devo, is early-stage open-source developer tooling for structured AI-assisted software development.

Contributions are welcome for documentation, bug reports, tests, workflow improvements, CLI usability, dashboard improvements, and integration ideas.

## How to contribute

1. Open an issue describing the bug, idea, or improvement.
2. Fork the repository.
3. Create a focused branch.
4. Add or update tests where reasonable.
5. Open a pull request with a clear summary and validation notes.

## Project goals

Devo should remain local-first, safety-first, and human-controlled. It should help developers manage AI-assisted work through context, approvals, validation evidence, delivery checks, reports, and recovery workflows.

## Non-goals

Devo should not silently execute destructive actions, hide risk from users, or bypass external security policies.
